Methodological Integrity & Transparency Notice
ASD models are trained on 996 real clinical records from the UCI ML Repository (704 Adults + 292 Children, CC BY 4.0, Fadi Thabtah 2017) with 75% Training Set (N=747) + 5-Fold Stratified Cross-Validation and an Untouched 25% Holdout Test Set (N=249). Age-group (child/adult) and sex (M/F) stratified metrics are reported. All target-derived features (aq10_sum, result) are excluded to prevent leakage. No synthetic augmentation was used — model trained on real data only. The 6 non-ASD disorder models use structured heuristic cohorts (N=1200) because no equivalent real public dataset exists for those conditions with this feature schema.
